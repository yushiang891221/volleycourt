# 架構規劃：伺服器當裁判（B 方案）

2026-11-15 定案。目的：遊戲要公開給大家玩，所以比賽結果一律由台北伺服器決定，每個玩家到裁判的距離都一樣（約 5 ms），房主離開比賽也不會中斷。

## 現況的問題

- `gym.html` 一個檔案約 13,000 行。「算球、判分、AI」和「畫 3D、介面、音效」寫在一起。
- 比賽由房主的瀏覽器負責判定，所以房主 0 延遲，其他人要多繞一圈；房主斷線，整場就結束。
- 比賽程式約 2,500 行，直接用到畫面物件（`b.m.position`、`walk.`、`toast(`、`$('…')`、`THREE.`）。

## 目標：分成三層，界線不能跨

| 層 | 負責 | 在哪裡跑 | 不可以碰 |
|---|---|---|---|
| **比賽引擎** `engine/` | 球的物理、碰網碰地、觸球次數、得分、發球、輪轉、換局、AI | 伺服器（正式判定）＋網頁（預測用） | THREE、DOM、音效、`walk`、`NET`、時間函式（時間由外面傳進來） |
| **伺服器** `vps/` | 每間比賽房跑一份引擎，固定每秒 60 步；收玩家操作、送出狀態；比賽結束寫戰績 | 台北伺服器 | 畫面 |
| **網頁** `gym.html` | 畫面、輸入、音效、介面；把伺服器的狀態平滑地畫出來 | 玩家瀏覽器 | 不再自己判定比賽結果 |

引擎的規則：
1. 只吃資料、只吐資料：`step(state, inputs, dt) → { state, events }`。
2. 提示文字、音效、特效都改成「事件」（例如 `{type:'point', team:1, why:'出界'}`），由網頁收到事件後再顯示或播放。
3. 不用亂數產生器以外的隨機（`Math.random` 改成引擎自己的種子亂數），同樣的輸入一定算出同樣的結果，才能做自動比對。

## 誰決定什麼

| 事情 | 由誰決定 | 說明 |
|---|---|---|
| 自己走路、跳躍 | 玩家自己的瀏覽器 | 按了馬上動，不等伺服器。伺服器檢查速度上限，太快就拉回 |
| 擊球（發、接、舉、扣、攔） | **伺服器** | 玩家送「我在第幾毫秒、在哪裡打到球」，伺服器拿過去 1 秒的球路紀錄比對（延遲補償），通過才算 |
| 球的飛行、碰網、落地、出界 | **伺服器** | 網頁照同一份引擎先算（看起來即時），伺服器結果到了再柔和修正 |
| 得分、發球權、輪轉、換局、比賽結束 | **伺服器** | |
| AI 球員 | **伺服器** | |
| 戰績、經驗、成就寫進 Supabase | **伺服器** | 用伺服器專用金鑰寫，玩家無法偽造 |

## 傳送內容

- 玩家 → 伺服器：自己的位置／朝向／姿勢（每 50 ms）、動作請求（擊球、發球，附時間與球的位置）。
- 伺服器 → 玩家：比賽快照（球、AI、比分、階段，每 50 ms）＋事件（觸球、得分、哨音，立刻送）。
- 時間：連線時對時，之後每 5 秒校正一次；快照都帶伺服器時間，網頁照時間軸播放。

## 分階段做法（每一階段都要自動檢查通過才進下一階段）

| 階段 | 內容 | 驗收 |
|---|---|---|
| B1 ✅ | 球的物理抽成 `engine/ball.js`（飛行、飄球、碰網、天花板、牆、落地彈跳）。2026-11-15 完成 | `tests/verify-engine-ball.cjs`：400 顆球、32 萬小步與舊版逐步比對，誤差 0；既有檢查全過 |
| B2 | 規則抽成 `engine/rules.js`（觸球次數、連擊、持球、越線、得分、發球 8 秒、輪轉、換局、比賽結束） | 錄下的幾場比賽事件重播，新舊判定完全一樣 |
| B3 | AI 抽成 `engine/ai.js`（2v2 與 6v6 的站位、接、舉、扣、攔、發球） | 固定種子下 AI 對 AI 打 50 球，新舊結果一樣 |
| B4 | 伺服器房間跑引擎（`vps/match.js`），先讓「全 AI 比賽＋觀戰」在伺服器上跑 | 1 vCPU 能同時跑的房間數實測；觀戰畫面順 |
| B5 | 網頁改接伺服器：送操作、收快照、本機預測＋修正；開房、開始比賽、結束都由伺服器管 | 兩個真人帳號實測：房主離開比賽照常；延遲、閃爍、飄移都比 A 好 |
| B6 | 戰績改由伺服器寫入；舊的「房主判定」留在練習模式（離線）用 | 戰績正確、玩家改不了 |

上線方式：B5 之前都不影響正式網站；B5 先用網址加 `?srv=1` 試玩，確認沒問題再改成預設。

## 容量估計（之後要實測）

引擎每一步只算一顆球和最多 12 個人，不畫畫面。推估 1 vCPU 可以同時跑幾十間房；不夠就在 LightNode 升級規格或多開一台。
