# 企劃：個人球衣客製（2026-11-16）

使用者需求：每個人可以設計自己的球衣。參考了一個實體球衣訂製網站的流程（選版型 → 顏色 → 正面／背面版位 → 字體 → 球褲），
遊戲裡做「同樣的流程、我們自己的畫面與名稱」，不放任何外部品牌標誌。

## 什麼時候穿哪一件

| 情境 | 穿的球衣 |
|---|---|
| 大廳、走動、練習房、陪練 | **自己設計的球衣**（在「球衣與裝備」選要穿哪一件） |
| 一般比賽（開始遊戲後） | 照舊：兩隊公認隊服（橘黑／藍白），**號碼用自己的** |
| 球隊戰（以後做：同球隊之間 PK、或球隊對球隊） | 球隊球衣（隊長設計的那件） |

比賽一結束、回到走動，自動換回自己選的那件。

## 設計器流程（放在「球衣與裝備 → 球衣 → 設計我的球衣」）

左邊：角色預覽（可轉，正面／背面並排或一鍵切換）。右邊五個分頁（照參考網站：版型 → 樣式 → 顏色 → 設計 → 球褲）：

1. **版型**
   - 衣服：運動球衣（短袖，可以有花紋）、練習 T（短袖素面，只能放字）、無袖（沿用現在捏臉的無袖）
   - 領口：圓領、交叉領（V 字交疊）
2. **樣式**（運動球衣才有；練習 T 跳過這頁）：一整面縮圖格子挑花紋，先做 **18 款**，之後再加。
   - 我們自己用程式畫的花紋（不抄參考網站的圖），分幾類：
     - 漸層類：上深下淺、側邊漸層、斜向漸層
     - 點陣類：點陣漸層（像參考圖的藍色款）、斜帶點陣、散點
     - 線條類：直條紋、細斜線、波浪、側邊條
     - 色塊類：肩膀撞色（插肩）、斜切大色塊、V 字色塊、幾何拼塊、胸前橫帶
     - 紋理類：迷彩點、碎紋、素面
   - 縮圖用玩家目前選的顏色即時畫，所以看到的就是穿起來的樣子。
3. **顏色**
   - **現成配色**：每個樣式附 6 組好看的配色（像參考圖：藍、酒紅、白、深藍綠、黑、海軍藍），點一下整件換好。
   - **自己調**：展開後用約 28 格色票分別選 主色、花紋色、領口／袖口邊、號碼與字。
4. **設計**（上面再分 正面／背面／字體 三個小分頁）
   - **正面版位**（三種，跟參考圖一樣）：
     - A：上排三個小格＋中間一行大字＋下面號碼
     - B：中間大字＋號碼置中
     - C：左胸小字＋右側直排
     - 每一格可以選「字」、「號碼」或「不放」
   - **背面**：領口下方小圖示（可關）、上面放名字（可以不印）、下面放大號碼
   - **字體**：6～8 種（粗黑、圓體、書法感、斜體運動風…），用「隊伍名稱 / NAME / 20」的樣字格子挑，同時套用正面字、背面名字和號碼
5. **球褲**：顏色（可跟球衣主色或邊色同色）、左下角放號碼（可關）

下方按鈕：「存檔並穿上」「取消」。可以存 **3 件**，在「球衣與裝備」切換。

## 規則

- 正面字、背面名字：各 1～8 個字，要過濾不雅字（跟暱稱共用同一套檢查）。
- 號碼 0～99，沿用捏臉的號碼。
- 字體只用有授權、可以免費商用的字（例如 Google Fonts 上的 Noto Sans TC、Anton 這類），而且要選能顯示中文的；只在打開設計器或看到別人穿時才下載，避免拖慢載入。
- 這是純外觀：不影響比賽計算，伺服器裁判的比賽核心不用改。

## 存在哪裡、別人怎麼看到

- 存到帳號（Supabase）：新增一個 `my_jerseys` 欄位，用一個伺服器函式 `set_my_jersey()` 檢查格式和文字後才寫進去。換電腦也在。
- 每一件球衣壓成一段短代碼（像現在的外觀代碼 `t2…`），連線時跟外觀一起送出，其他玩家照代碼畫出來。
  - 不會增加每秒傳的訊息量：只在進房、換衣服的時候送一次。
- 現在的「球隊球衣」只存在這台電腦，順便改成從帳號讀。

## 分段做法

| 段 | 內容 | 完成時看得到什麼 |
|---|---|---|
| J1 | 球衣代碼格式＋貼圖畫法（領口、18 款樣式、配色、正面字、背面名字、字體）＋單元檢查 | 用代碼就能畫出各種球衣 |
| J2 | 設計器畫面（四個分頁、預覽可轉、正背面）＋存在這台電腦 | 自己可以設計、穿上 |
| J3 | 存到帳號（Supabase 欄位、檢查函式、不雅字過濾）＋存 3 件切換 | 換電腦還在 |
| J4 | 連線：代碼跟外觀一起送；別人看到你的球衣；比賽開始換隊服、結束換回 | 大廳裡大家看到彼此的球衣 |
| J5 | 球隊戰穿球隊球衣（等球隊戰做好） | — |

每段做完都要：自動檢查全過、瀏覽器左右轉身都看過（鏡像曾經出過問題）、低畫質也正常。
