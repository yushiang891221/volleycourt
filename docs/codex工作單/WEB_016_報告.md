## 完成內容

- 新增 `server/supabase/013_last_seen.sql`，可重複執行，新增可為 null 的 `last_seen_at`，不授予一般使用者直接寫入權限。

- 離線文字每分鐘重新計算，支援剛剛、分鐘、小時、天；沒有紀錄只顯示離線。離線列變淡且標籤灰色，保留右鍵選單、個人檔案與好友入口。
- 人數顯示「在線 N 人・共 N 人」，維持每頁 8 人。帳號 RPC 失敗時清除帳號清單，回到原本在線清單與人數格式，不顯示錯誤。
- 好友面板仍使用原本 `players` 即時在線名單判斷綠點。
