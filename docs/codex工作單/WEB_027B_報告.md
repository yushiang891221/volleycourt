## 本輪修改

- `css/lobby-ranked.css`：六人站位改成上下兩個不重疊的區域，後排略向兩側錯開；名牌置於各自角色視窗上方，縮成隨文字寬度的兩行，長文字截斷。前排自己置中，角色視窗高度為隊友的 1.25 倍；兩人模式自己位於中間偏左、隊友在右，維持相同比例。
- `js/lobby-ranked.js`：標示自己的站位，搭配香檳金名牌及既有「你」文字；手機仍只渲染自己的 3D 角色，隊友保留頭像卡片。
- `js/character-panel.js`：自己的角色腳下新增香檳金環形底座，與既有 renderer、scene 及鏡頭共用；離頁釋放底座資源。
- `index.html`、`js/lobby.js`：留言板預設收合為最新一則訊息加展開鈕，展開後恢復歷史訊息與輸入表單，支援再次收合及 aria-expanded 狀態更新。原訊息接收、發送與跑馬燈保留。留言板縮小後，舞台取得剩餘高度。
- 將原 `practice` 按鈕 ID 移到上方「練習」，沿用既有練習事件；移除底部重複的練習模式與天梯排行榜，其餘按鈕保留。自訂房間功能未改。
- `tests/verify-web027.cjs`：新增入口唯一、預設收合、展開／收合事件、名牌樣式與不同舞台高度的排間距及尺寸比例檢查。
