# WEB-017 房間聊天完成報告

完成日期為 2026-11-13，工作分支為 `game-site`。

## 完成功能

- 電腦版連線房間按 Enter 開啟並聚焦聊天輸入框，再按 Enter 送出並關閉。空訊息直接關閉，Esc 取消。中文輸入法組字期間的 Enter 保留給確認選字。
- 最先註冊的 capture 鍵盤處理攔截聊天期間所有遊戲 keydown，包含自訂按鍵。也攔截相關 keyup，避免放開 T 或數字鍵時觸發遊戲。開啟時清空移動鍵、目標移動、速度、蹲下及選單狀態，輸入期間停止水平移動。
- 「房主開始遊戲」預設改為 **G（KeyG）**。預設按鍵沒有重複。舊設定的開始鍵若為 Enter，會遷移到 G；G 已被其他自訂動作使用時，替該動作安排空閒鍵。其他動作若使用 Enter，也會移至空閒鍵。保留其他有效的自訂開始鍵，設定畫面新增固定 Enter 聊天說明。
- 使用現有 `NET.tx.publish('chat', { id, n, t })`，只有使用者送出時傳送。送出端每秒最多一則，送收均清除控制字元、去除前後空白並依 Unicode 碼點截為 60 字。
- 左下聊天紀錄保留最近六則，以「名字：內容」顯示，自己訊息使用青綠色。各則約八秒後淡出，輸入框開啟時顯示全部紀錄，可捲動查看。
- 聊天區依計分／輪轉區、底部按鍵提示及場館資訊卡尺寸調整底部位置與紀錄高度。測試涵蓋 900、720、600 像素高的模擬版面。
- 頭上對話泡泡持續約四秒，逐畫格追蹤玩家位置，與名牌分開，觀眾視角也更新。自己的泡泡在第三人稱顯示。AI 不會產生聊天泡泡。
- 聊天文字與泡泡一律以 `textContent` 顯示。未連線練習模式不開聊天。離房時清理聊天介面、泡泡與版面觀察器。
