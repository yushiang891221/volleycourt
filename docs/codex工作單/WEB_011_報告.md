## 強度 k 的最終算法

採用工作單的起跳前體力比例備案：有體力系統時 `k = clamp(STA.v, 0, 1)`（體力上限為 1），沒有體力系統時 `k = 1`，體力不足只能小跳時 `k = 0`。

原因：實際 `staEff()` 回傳 0.8～1，因此現有 `tired = 0.4 + 0.6 * staPay()` 的範圍是約 0.88～1；直接換算只會得到 0.8～1，無法符合低體力接近不輔助的需求。起跳高度與原有 tired 計算未變更。
