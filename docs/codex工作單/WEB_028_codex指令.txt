   - send(ws, obj)：送訊息給某個連線；sockets()：目前所有大廳連線；now()：現在時間（測試可以換假時鐘）。
   - 每個連線的資料在 ws.meta：{ id, token, player（帳號 id）, name, status, no }。訪客怎麼分辨，請看 server\rt\server.mjs 和 server\shared\verify-player.mjs 現在的做法。
   - handle(ws, m)：m.k 是 party- 開頭的訊息就處理並回傳 true，其他回傳 false。
   - bye(ws)：連線關掉時呼叫（60 秒沒回來才移出隊伍）。
   - 計時器要能清掉（提供 stop()），測試才不會卡住。
