# 工作單 WEB-002B：開場畫面、扣球動畫、「開始遊戲」按鈕

建立：2026-11-04。在 `volleycourt` 的 `game-site` 分支做（目前 `dfccdf3`，含 WEB-002 大廳伺服器）。
先讀：`tickets.md` Ticket 4、`codex工作單/WEB_002_報告.md`。

## 背景
WEB-001 把舊網站的開場（`index.html` 的 `#intro` 開始畫面＋`spike3d.js` 3D 扣球動畫）跟企劃一起刪掉了。使用者要把開場動畫和「開始遊戲」按鈕加回來，流程變成：

**進網站 → 開始畫面 → 按「開始遊戲」→ 播扣球動畫 → 進大廳（第一次會先問暱稱）**

舊版程式在 `main` 歷史的 `fe7e31f`：
- `git show fe7e31f:spike3d.js`（3D 扣球動畫，整個檔拿回來）
- `git show fe7e31f:index.html`：`<section id="intro">`（約 905 行）、相關 CSS、轉轉的排球 canvas（`#ball`、`spin`）、`go()`／`loadSpike()`／`#anim3d`／`#phase`／`#flash` 的流程（約 1250～1300 行）。

## 要做的事
1. **開始畫面**（蓋在大廳上的全螢幕層，風格跟大廳一致或沿用舊開場的樣子）：
   - 轉動的排球、標題「排球遊戲」，副標題一句跟遊戲有關的話（不要再出現「企劃」「新竹排球館」「廠房」「地圖」）。
   - 大按鈕「**開始遊戲**」（橘色）；小字連結「跳過動畫」。
   - 點排球也等於開始。
2. **按開始遊戲**：播 `spike3d.js` 的扣球動畫（舊版的階段文字 `#phase` 可以留），播完淡出進大廳；結尾原本是「飛進地圖」，改成淡入大廳。
   - 動畫載入失敗或使用者系統設定「減少動態」（`prefers-reduced-motion`）→ 直接淡入大廳。
   - 動畫播放中可以按 Esc 或點「跳過」直接進大廳。
3. **進大廳後**：第一次來的人才跳暱稱視窗（沿用現在的）。大廳伺服器連線可以在開始畫面時就先在背景連，進大廳時資料已經好了。
4. **什麼時候顯示開始畫面**：
   - 直接打開網站（`/`、`index.html`）→ 每次都顯示。
   - 從遊戲按「回大廳」、`gym.html` 沒參數被導回、或任何站內回大廳 → **不顯示**，直接到大廳。做法：這些連結都改成 `index.html#lobby`（或你覺得更好的方式，寫進報告），開始畫面看到 `#lobby` 就跳過。
   - 邀請連結（直接進 `gym.html?...room=`）不受影響。
5. 開始畫面和動畫期間，大廳的按鈕不能被點到、鍵盤 Tab 也不會跑到底下的大廳。

## 不要做
- 不改大廳伺服器、房間連線、玩法。
- 不推送、不部署，不動 `main`、`planning-site`。只做電腦版。

## 驗收
1. 本機 `python -m http.server 5180 -d volleycourt` 開 `/`：看到開始畫面 → 按開始遊戲 → 動畫 → 大廳；主控台沒有新錯誤（本機 api 404 除外）。
2. 「跳過動畫」、點排球、Esc 跳過都正常。
3. 進房再按「回大廳」→ 直接是大廳，沒有開始畫面。
4. 1920×1080、1366×768 開始畫面置中、不出現捲軸。
5. grep 不到「企劃」「新竹排球館」等舊字樣出現在網站畫面上。
6. 舊的自動檢查（`tools/verify-web001c.cjs`、`verify-web002-state.cjs`）還是全過；有改到網址的斷言就一起更新。
