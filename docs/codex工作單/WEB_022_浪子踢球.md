## 動作拆解（使用者描述＋截圖）
使用者強調三個重點：**手臂翻的方向**、**腳要勾起來（勾腳：腳尖往上翹、腳跟往外送）**、**頭要轉向踢腳那邊**。
1. **準備**（圖 1）：站直，雙手自然垂在身體兩側、微微張開。
2. **起手**（圖 2）：雙手往兩側抬到約肩膀高，手肘彎、前臂往下垂、握拳；一隻腳的腳跟抬起、膝蓋微彎，重心移到另一腳。
3. **翻手、閃身**（圖 3）：上半身往一側傾＋扭，膝蓋彎、重心壓低；兩隻手臂跟著**翻轉**（一手手肘往上翻、一手往下壓，像翅膀拍一下），頭開始轉、往下看要踢的那一邊。
4. **踢**（圖 4、圖 5）：**勾腳**往後外側踢出去（腳跟帶頭），支撐腳彎曲；上半身往踢腳的反方向閃，頭轉過去看著踢出去的腳。整個踢的瞬間要很快、有頓挫感。
5. **換邊**（圖 6）：雙手往上翻成「舉起、手肘彎、拳頭朝上」，另一隻腳**勾腳**往前交叉踢出，頭轉向那一邊。
6. **收**：回到站姿。
整段約 1.6～2 秒（兩邊各踢一次）。節奏是「準備慢 → 翻手、踢很快 → 稍停 → 換邊踢很快 → 收」。
（截圖是畫面左右，請自己判斷人物的左右腳；角色做出來左右哪隻腳先踢都可以，但兩次要不同腳。）

## 要做的事
1. **浪子踢球**：代碼 `langzi`（符合 `^[a-z0-9]{1,12}$`），名稱「浪子踢球」，圖示自己挑。加進 `progress.js` 的 `EMOTES`，**一開始就能用**。用 WEB-021 的關鍵影格系統做，關節照上面拆解，注意手臂翻轉方向、勾腳（腳踝如果骨架沒有可以控制的關節，就用膝蓋與小腿角度做出腳跟往外送的感覺，寫進報告）、頭跟著轉（`AVP` 若沒有頭部轉向，請加上頭／脖子的轉動控制；做不到就用上半身扭轉代替並寫進報告）。
   - 原地動作，不位移。
2. **使用時機**：跟閃身步一樣——**發球之後到死球之前不能用**（含發球員拋球中），播放中遇到發球立刻中斷。死球後、等待發球、場下、觀眾、練習可以用。
3. **真的把地上的球踢飛**：
   - 踢腳那一下（第 4 段、第 5 段的踢出瞬間各判一次），如果**踢的那隻腳附近（約 0.8 m 內）有一顆幾乎停住的球**（在地上滾動慢下來或停住：速度 < 1.5 m/s、高度貼地），就把球踢飛：方向照腳踢出去的方向，初速約 7～10 m/s、帶一點往上的角度（約 25～40 度），有點隨機。一次動作最多踢到一顆球。
   - 比賽中：只在死球後、等待發球時才可能發生（上面規則已經擋掉回合中）。被踢飛的球**不算觸球、不影響比分、統計、成就、評分**，主機的判分、發球流程完全不理它。到了換人發球（現在 `vmClearBalls`／發球員拿球的流程），照原本流程清掉場上的球，**球還是回到發球員手上**，不能因為球被踢走而卡住發球或讓發球員拿不到球。
   - 不在比賽中（場下、練習、自由走動）：地上停住的球也可以踢。
   - 連線：踢中時用現有的球同步方式（`netBallHit` 那一套）讓大家看到同一顆球飛出去；比賽中目前會忽略 `w === 'throw'` 的球，請用一個新的種類（例如 `w: 'kick'`），並確認它在比賽中**不會**取代或干擾比賽球、不會被當成觸球；如果現有規則會讓收方忽略它，就調整成「死球期間允許顯示踢飛的球，但不計任何比賽事件」。
   - 動作本身的播放照 WEB-021：只送一則 `emo`，收方自己播放；踢球另外只在踢中那一下送一則球的訊息。
4. 第一人稱、第三人稱、觀眾視角都正常。
