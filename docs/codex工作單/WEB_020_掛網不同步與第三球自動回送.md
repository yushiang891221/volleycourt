# 工作單 WEB-020：別人打的球掛網結果不同步、第三下自動把球送回對面

建立：2026-11-13。在 `volleycourt` 的 `game-site` 分支做，**要在 WEB-019 提交之後**。只做電腦版。
Codex 用量不可超過 50%；做完就停。先讀 `codex工作單/WEB_015_報告.md`、`WEB_018_報告.md`（連線播放與球的修正）。

## 一、別人打的球：碰網／掛網結果跟打的人看到的不一樣

### 使用者回報
隊友扣球，在**隊友自己的畫面是直接釘在地板上**；在使用者的畫面卻是**掛網、或打到網子才過去**。

### 原因（規劃端判斷，請先查證再改）
- 每台電腦各自算球的物理。擊球的人（`NET.ownBall`）送出擊球那一下的位置與速度，之後回合中每 400 ms 校正一次；碰網時馬上送一次（`b.netEv` → `m.n = 1`，約 6795 行）。
- 收到的人：照延遲往前補，再用 `b.err` 慢慢修正（WEB-018 改成 0.25 秒）。修正還沒完成時，本機的球位置跟擊球者差一點點，**本機自己的網子碰撞就可能判成掛網／擦網**，跟擊球者的結果分岔。
- 比賽判分在主機（`VM.host`）用**主機本機的球**判；主機如果不是擊球者，判出來的結果也可能跟擊球者不同。

### 要做的事
1. **不是我負責的球（別人打的、`b.room && !NET.ownBall`），本機不自己判碰網**：網子碰撞（掛網、擦網反彈、網帶）一律以負責的人送來的結果為準——負責的人碰網會馬上送 `n`，收到時照現有 `d.n && sameOwner` 直接對齊。本機的球在等待期間照負責的人給的路線飛，可以穿過網的平面（不要在本機反彈）。
   - 本機玩家**自己的攔網判定**（`vbBlockTest`、我去攔別人的球）要照常運作——攔到之後球就變成我負責。
   - AI 的攔網只有主機在算，主機上 AI 攔到時主機變成負責的人，照現有流程。
   - WEB-018 的「修正途中低低穿網就直接對齊」保護，對不是我負責的球改成：照負責的人路線判斷要不要對齊，不要因為本機修正路徑而誤觸。
2. **落地也以負責的人為準**：負責的人的球第一次碰到地板時，馬上送一則（只有事件發生時才送，像碰網那樣），帶落地位置。收到的人把球對齊到那個落地點。主機判分（界內／界外、哪一隊失分）要用**負責的人回報的落地點**；主機自己就是負責的人時照舊。
   - 先查清楚現在主機怎麼判落地（`vmJudge` 等），寫進報告；只改「用誰的落地點」，不改判分規則本身。
   - 送出的人斷線或遲遲沒回報（例如 0.5 秒內沒收到落地），主機退回用自己本機的結果，不能卡住比賽。
3. 訊息數：只增加「每一球最多一則落地事件」，其他節奏不變。流量照 WEB-015 的方法模擬，報告寫改前改後數字。

## 二、第三下：碰得到就自動送回對面

### 使用者要的
一隊的第一下、第二下把球救起來（例如球被打飛出界、touch out 之後救回來），**第三個碰到球的人，只要碰得到，就自動把球送回對面**，不用面向正確的方向。**只限第三下**。

### 現況
- `vbReceive()`（約 9528 行）第三球（`vmThird()`）下手送過網用 `vbFacingOverVel()`——**照面向的方向**，面向旁邊或背對就送不過去；接球品質差（`q < 0.32`）時球亂飛。
- 已經有自動瞄對面的 `vbOverVel()`（約 9662 行，`back` 的情況在用）。

### 要做的事
1. 比賽中（`VM.on`、rally），輪到自己這隊第三下（`vmThird()` 為真）時，本機玩家**不是扣球／吊球**的觸球（接球、墊球、撲救、舉球、推球過網等）一律用自動瞄準送回對面：走 `vbOverVel()` 這類路線（高弧線、落在對面場內深處、過網高度足夠），**不管面向**。
   - 接球品質差時，落點可以偏、弧線可以低一點，但仍然要過網、方向朝對面（不要亂飛回自己場上或往旁邊）。品質非常差（現在的 `q < 0.32`）也照樣送過網，只是落點誤差大一點、可能出界。
   - 扣球、吊球、跳起來攻擊照現有瞄準規則，不受影響。
   - 第一下、第二下完全照舊（還是照面向）。
2. 提示文字：第三下自動送過網時，畫面提示顯示「第三下：自動送回對面」。
3. AI 不用改（AI 第三下本來就會送過去，查一下確認，寫進報告）。
4. 新手教學、練習模式（沒在比賽）不受影響。

## 不要做
- 不改評分、成就、聊天、介面配置、AI 戰術。不做手機版。不改 `blender/`、`models/`、`rt-worker/`、SQL。不推送、不部署。一行程式中間的註解用 `/* */`。
