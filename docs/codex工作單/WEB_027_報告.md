## 接口

`window.PlayOneLobby` 提供 `setParty(members)`、`setMyRating({rating,tier,placed})`、`setMatchState({state,seconds,note})`、`onStartMatch(mode)`。setParty 第一筆約定為自己，其餘為隊友；空陣列回復自己一人。placed 為完成定級場數（10 或 true 表示已定級）。

另預留 `onCancelMatch(mode)`、`onStartAI(mode)`、`openInvite(name)`。所有配對按鈕預設只提示未開放；邀請開空清單框，複製邀請連結只提示未開放，不製造無效組隊連結。
