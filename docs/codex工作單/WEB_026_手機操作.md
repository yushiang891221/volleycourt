# 工作單 WEB-026：手機操作（五顆鈕＋拖曳瞄準）

建立：2026-11-17。在 `volleycourt` 的 `game-site` 分支做。**只做手機（觸控）操作，手把不做。**
Codex 用量不可超過 50%；做完就停，額度快不夠時先把進度寫進報告再停。

## 最重要的規則：不可以影響電腦版
- 手機操作全部寫在**新檔** `src/gym/game/15-touch.js`（編號照現有檔案接；如果建置工具要求別的位置，照建置工具）。
- 只在觸控裝置啟動：沿用現有判斷 `matchMedia('(pointer: coarse)')`。電腦（滑鼠）開遊戲時，新檔裡的東西都不顯示、不監聽任何事件。
- 原本的鍵盤、滑鼠程式**不改行為**。如果真的需要動舊檔，只能加「手機才會設定的值，沒設定就照舊」這種寫法（例如 `walk.touchAim` 是 null 時，完全照原本的 `walk.yaw`、`walk.pitch`），每一處都要在報告列出來。
- 判定、時機、伺服器裁判、網路訊息都不改。手機玩家不能比電腦玩家多任何輔助（不放寬接球範圍、不自動跑位）。

- 搖桿程式在 `09-replay.js` 約 690～715 行，設定 `walk.joy`、`walk.joyRun`。
- 電腦版規則（手機要照這些規則，只是換操作方式）：
  - 扣球方向＝面向 `walk.yaw`；深淺＝視角 `walk.pitch`（`11-volley-control.js` 約 572 行：平視打到網後約 6.6 m，往下看約 35 度＝網後約 2 m，越往下越釘）。
  - 扣球力道＝按住時間（`CHG`、`vbChargeStart`，約 494～530 行），有甜蜜點；起跳前先按住，起跳那一刻開始蓄力（`walk.chargeArm`、`chargeArmGround`）。

  - 舉球輪盤：`setWheelOpen()`、`setMenuMove(dx, dy)`、`setMenuClose(true)`（約 815 行起）。
  - 攔網左右：`walk.blkAim`（約 1071 行，電腦版用滑鼠左右移）。
  - 情境提示：`vbCue` 算出的 `cue[0]`（`jump`、`hit`、`set`、`block`，還有接球）就是「現在該按什麼」。

## 要做的事
### A. 遊戲中畫面越少越好
1. 手機遊戲中只留：**左下搖桿**、**右下五顆鈕**、**右上一顆小選單鈕**、計分板、體力條。
2. 其他東西（按鍵提示面板、練習房的按鍵面板、聊天框、表情、錄影鈕、提示文字等）在手機上收進選單鈕，或縮到不擋畫面。請先在手機模擬畫面截圖，列出現在畫面上所有東西，報告裡寫每一項怎麼處理。
3. 直拿手機時顯示「請把手機橫放」。
4. 舊的 `#vpad` 拿掉，換成新的五顆鈕。舊的 4號位、快攻、2號位、後排鈕不要了（改用輪盤）；「傳（拋給隊友）」只在非比賽閒逛時需要，收進選單或只在那時出現。

### B. 五顆鈕：跳、扣（發）、舉、接、攔
1. 排在右下，手指好按（每顆至少 64 px，主要的「扣」最大）。
2. 當下該按的那顆**亮起來**（照 `cue[0]`），其他的變淡但**仍然可以按**（不能因為提示判斷錯就按不了）。
3. 按下時輕微震動（舊程式已有 `navigator.vibrate(12)`）。

### C. 移動（搖桿）
1. 輕推＝慢走，推到底＝跑（現有 `walk.joyRun` 規則保留）。
2. **在球場上（練習、比賽）拿掉「放開後鎖定自動跑步」**，放開就停，免得接球時人自己跑走。閒逛時可以保留。
3. 跑動中按「接」＝撲救（電腦版已有，確認手機也觸發）。

### D. 接
按「接」＝電腦版的接球鍵。不加任何自動跑位。

### E. 舉（輪盤）
1. **按住「舉」**＝打開舉球輪盤（`setWheelOpen`）。
2. 手指拖動＝移動輪盤游標（`setMenuMove`，用按下點的位移）。
3. **放開＝舉出去**（`setMenuClose(true)`）；按一下沒拖＝預設舉球，跟電腦版點一下一樣。
4. 輪盤要畫在手指旁邊、夠大，不要被手指擋住要選的那格（例如輪盤中心放在按鈕左上方）。

### F. 扣（發）：拖曳決定方向和深淺，按住時間決定力道
1. **在地上按住「扣」**＝起跳並開始蓄力（照電腦版 `chargeArmGround`：起跳那一刻開始蓄力）。
2. **在空中按住「扣」**＝開始蓄力。
3. 按住期間手指拖動（以按下點為準）：
   - 左右＝方向：在面向左右各約 35 度內調整。
   - 往上＝打長（`pitch` 往上，落點接近底線）。
   - 往下＝往下扣、釘（`pitch` 往下，落點靠近網子）。
   - 沒拖＝照目前面向、中等深度。
4. 拖動時在**對面場地顯示落點圈**，跟著手指移動，位置要跟實際落點公式一致（先看 `vbAimRing` 能不能直接用）。
5. **放開＝揮臂**，力道照電腦版蓄力規則（同樣有甜蜜點，蓄力條照常顯示）。
6. **在空中輕點一下馬上放開（約 0.15 秒內、幾乎沒拖）＝吊球**。
7. 做法建議：新增 `walk.touchAim = { dyaw, pitch }`，只有手機設定；擊球那一刻如果有值就用它取代 `walk.yaw` 的偏移和 `walk.pitch`，用完清掉。電腦版永遠是 null。
8. 發球：拿著球時「扣」就是發球，同樣可以按住拖曳瞄準、放開發出去；跳發照電腦版規則。

### G. 攔
1. 按住「攔」＝起跳攔網。
2. 按住期間左右拖＝`walk.blkAim` 往左右（範圍、速度照電腦版滑鼠）。

### H. 視角
在空白處拖動畫面＝轉視角（現有行為保留）。按住任何一顆鈕時拖動不能轉到視角。
