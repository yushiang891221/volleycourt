# 工作單 WEB-001C：進房不閃平面圖、右上角按鈕整理、個人設定面板

建立：2026-11-04。接在 WEB-001B（`game-site` 分支 `9351dab`）之後，同一分支做。
先讀：`tickets.md` 的 Ticket 4、`codex工作單/WEB_001B_報告.md`。

## 1. 進房間時不要閃出平面設計圖
使用者回報：從大廳開房／加入／練習進 `gym.html` 時，會先閃一下室內設計平面圖，才變成球館。
- 找出原因（推測是頁面先用平面圖模式畫出來，`generateFromSite()` 完成後才 `setMode('walk')`）。
- 改成：一進頁面就蓋一層全螢幕的載入畫面（跟大廳同風格：深色底、橘色、顯示「進入球館中…」和進度），球館和 3D 準備好、切到走動模式後才淡出。整個過程都不能看到平面圖或任何企劃介面。
- 「看平面圖」「離開導覽」這兩個按鈕在遊戲裡不需要，拿掉（離開改成「回大廳」）。

## 2. 右上角按鈕整理
現在右上角有：多人連線、畫質、音效、球速、接球輔助、全螢幕、看平面圖、離開導覽。改成：

- **多人連線**：拿掉按鈕和整個多人連線面板（`mp-*`：名字、開新房間、代碼加入、邀請連結）。進房間、名字都由大廳處理，`?room=` 自動加入照舊。房間內要看的資訊（房號、人數、名單）改放在一個小的房間資訊列（例如左上角：房名／房號、人數 x/20、連線狀態），不要大面板。
- **房主設定**（影響全房間、大家要一致的）：**球速**放這裡。只有房主能改，改了廣播給房間所有人，後來加入的人也要拿到現在的值。誰是房主：先用「建立房間的人」（網址帶 `host=1`，大廳開房時加上），房主離開就由房間裡最早進來的人接手。WEB-003 會再做完整的房間流程，這裡先做最小可用的。練習模式自己就是房主。
- **個人設定**（每個人自己改、只影響自己）：畫質、音效、接球輔助、全螢幕，全部搬進下面第 3 點的設定面板。
- 右上角最後只留：「房主設定」（只有房主看得到）、「設定」（齒輪）、「回大廳」。按 Esc 也能打開設定面板（如果 Esc 原本有用途，先確認不衝突，衝突就寫進報告）。

## 3. 個人設定面板：照 Godot 版搬過來
參考 Godot 版 `D:\開排球場\volley-game\src\prefs.gd`、`prefs_panel.gd`（只讀，不要改 Godot 專案）。做成網頁版的面板，風格跟大廳一致；大廳底部的「系統設定」也打開同一個面板（共用程式，例如放在 `settings.js`／`settings.css`，大廳和遊戲頁都載入）。

分頁與內容（網頁版沒有的功能就不要做假的選項，寫進報告）：
- **遊戲**：接球輔助（對方打過來時身體輕輕被帶到落點）、視角輔助、落點圈、按鍵提示、預設第三人稱、顯示隊友耐力圈。網頁版有哪些就接哪些，沒有的不要硬加新玩法。
- **畫面**：全螢幕／視窗、畫質（網頁版現有的高／省電，若能自然分成更多段再分）、視野（廣角）滑桿。
- **控制**：滑鼠靈敏度；按鍵綁定（點一下再按新鍵，重複時兩鍵互換、全部還原預設）；舉球面板左右對調。按鍵清單以**網頁版 gym.html 現在真的有的按鍵**為準，不是照抄 Godot 的清單。
- **音效**：主音量滑桿、靜音（網頁版有分類音效的話可以分開調）。
- **其他**：暱稱（2～12 字，跟大廳的 `vb.mp.name` 是同一個）、還原所有設定。
- 設定存在 localStorage（一個 key，例如 `vb.settings`，JSON），改了馬上生效、不用重新整理。之後 WEB-004 有帳號時會同步到帳號，所以讀寫集中在一個地方。
- 改按鍵綁定要真的改到遊戲裡的按鍵判斷，**但不能改變玩法和手感**：預設按鍵和現在完全一樣，沒改過設定的人玩起來要跟原本一模一樣。

## 不要做
- 不改物理、擊球、AI、連線協定（球速同步是新增一則房主訊息，不改原本訊息格式）。
- 不推送、不部署，不動 `main`、`planning-site`。只做電腦版。

## 驗收
1. 本機伺服器（`python -m http.server 5180 -d volleycourt`）開大廳 → 開房 → 從頭到尾看不到平面圖。
2. 右上角只剩房主設定（房主才有）、設定、回大廳。
3. 設定面板五個分頁都能用；改畫質、音量、接球輔助、靈敏度馬上生效；重新整理後還在；大廳的「系統設定」打開的是同一個面板。
4. 改一個按鍵後遊戲裡用新鍵有效、舊鍵無效；「還原預設」後恢復。
5. 用兩個分頁進同一個房間（本機會走 BroadcastChannel 測試線路）：房主改球速，另一個分頁也變。
6. 主控台除了本機 api 404 以外沒有新錯誤。
