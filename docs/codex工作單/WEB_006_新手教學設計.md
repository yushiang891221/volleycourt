# WEB-006 新手教學：共用設計（A、B 兩張工作單都照這份）

建立：2026-11-10。程式在 `D:\開排球場\volleycourt`，分支 `game-site`。只做電腦版（不做觸控、搖桿、手機版面）。
規劃來源：`D:\開排球場\volley-game\docs\ROADMAP.md` 第 1 階段。玩法、數值以現有 `gym.html` 為準：**教學只是「帶著做、偵測有沒有做到」，不改任何玩法、物理、擊球判定、AI、連線協定。**

## 玩家看到的樣子
1. 練習房（`gym.html?practice=1`）右上或房間資訊框附近多一顆「📘 新手教學」按鈕。也接受網址參數 `tutorial=1`：進練習房就自動打開教學選單。
2. 教學選單：列出六個段落，做完的打 ✓，每段可以點「開始」或「再練一次」。最下面「重設教學進度」。
3. 開始一段後，畫面上方中間（不要擋準星、不要擋房間資訊框和右側操作說明）出現教學面板：
   - 段落名稱、第幾步／共幾步（例如「接球 2／4」）
   - 這一步要做什麼（一兩句白話）＋要按的鍵（用 `<kbd>` 顯示）
   - 做到時面板閃綠、顯示「做到了！」約 0.8 秒後自動進下一步
   - 做錯或太久沒做到時（例如揮空、接球失誤），面板顯示小提示（例如「太早按了，等球亮起來再按」），不扣分、不退步
   - 面板上有「略過這步」「離開教學」兩顆按鈕（滑鼠放開時才點得到，這樣就好，不加新按鍵）
4. 一段的最後一步做完：顯示「這段完成！」，記進度，面板提供「下一段」「回選單」。
5. 六段全部完成：恭喜訊息。

## 按鍵顯示一定要照玩家自己的設定
按鍵可以在設定裡改（`settings.js` 的 `bindings`）。提示裡的鍵名一律用
`VBSettings.keyName(VBSettings.values.keys[動作])` 取得，不准寫死 `V`、`B`、`Shift` 等字。
滑鼠左右鍵、滾輪、Esc 不能改，可以直接寫「左鍵」「右鍵」「滾輪」。
注意：接球鍵是 `v`（別名 `q`），蹲下是 `crouch`（預設 Ctrl），衝刺是 `shift`。ROADMAP 寫的「C 接球」是舊的，以程式為準。

## 程式結構
- 新檔 `tutorial.js`：教學的段落／步驟定義、步驟狀態機、進度存取、教學面板與選單的 DOM。
  - 盡量寫成**不碰 three.js 也能在 node 裡測**：狀態機只吃「事件」和「每格狀態快照」，回傳要顯示的內容。
  - 對外：`window.VBTutorial = { open(), start(sectionId), stop(), active, progress(), reset(), emit(name, data), frame(snapshot) }`（名稱可以調整，寫進報告）。
- `gym.html` 只加少量接線：
  1. 載入 `tutorial.js`，練習房才啟用。
  2. 一個小函式 `tutEv(name, data)`：教學沒開時什麼都不做；在下面「事件表」列的地方各呼叫一次。**一行程式中間要加註解請用 `/* */`**。
  3. 每格（`updateWalk` 結尾附近）呼叫 `VBTutorial.frame(快照)`，快照內容見下面。
  4. 教學需要的「教練動作」（拋球、發球、扣球過來、叫陪練、給球、叫隊友）用現有函式組出來，放在 gym.html 一個 `TUT_COACH` 物件裡給 tutorial.js 呼叫。
- 教學進行中：體力不扣（`staGame()` 在教學中回傳 false，或教學不用會開體力的東西）；不影響非教學的練習與比賽。
- 進度存在 `localStorage` 的 `vb.tutorial`：`{ v: 1, done: { move: true, ... }, at: { 段落: 做到第幾步 }, updated: 時間 }`。讀壞掉的資料要當成空進度，不能讓遊戲壞掉；存不進去（無痕、被擋）也不能壞。之後要同步到帳號，所以進度只從 `progress()`／`reset()` 存取，格式固定。

### 每格快照（frame 用）
`{ x, z, yaw, pitch, speed（水平速度 m/s）, sprint（正在衝刺）, crouch, air（在空中）, airBlock（攔網跳）, blkAim, locked（滑鼠已鎖定）, tp（第三人稱）, hold（手上有球）, nearNet（離網距離 m）, onCourt, incoming（正在飛向自己這半場的球的預測落點 {x,z} 或 null）}`
欄位可以照實際需要增減，寫進報告。

### 事件表（在 gym.html 對應的地方呼叫 `tutEv`）
| 事件 | 觸發位置（先自己確認） | data |
|---|---|---|
| `recv` | 接球成功送出球（`vbRecvStep` 裡算出 `lastRecv` 那裡） | `{ q, dive, crouch }` |
| `recvMiss` | 接球按了但球沒碰到（窗口過了） | `{}` |
| `set` | 舉球送出（`vbDoSet`） | `{ n（1～6 鍵，6 鍵是 7）, v（舉法 key，例如 high/flat/quick）, menu（是不是用拖滑鼠選的）, def（是不是預設舉法）}` |
| `jump` | `vbJump` 真的跳起來之後 | `{ block, speed }` |
| `atk` | `vbHitAttack` 打到球 | `{ tip, air, chg, zone, q }` |
| `whiff` | `vbSwingStep` 揮空 | `{}` |
| `serve` | `serveLaunch`（站發、站飄）、`jumpServeHit`（跳發、跳飄） | `{ type: 'std'|'float'|'jump'|'jfloat', zone }` |
| `block` | `vbBlockTest` 判定碰到攔網手 | `{ kind（stuff/soft/through/top…）, aim: blkAim, mate（旁邊有沒有隊友一起攔）}` |
| `dive` | `vbDive` 撲出去 | `{}` |

## 六個段落（每段 3～4 步）
做到條件裡的數字是建議值，太難或太簡單可以調，調了寫進報告。

### 1 `move` 移動與視角
1. 點畫面鎖定滑鼠 → `locked` 為真
2. 用 W A S D 走到地上的黃色圈（教學在玩家前方約 4 m 畫一個圈）→ 進圈
3. 移動滑鼠轉頭，看向另一個圈（左右轉超過約 90 度）→ yaw 累積變化 > 1.5
4. 按住衝刺鍵跑到遠一點的圈（約 8 m）→ 衝刺狀態下進圈
5. 按住蹲下鍵 1 秒 → `crouch` 持續 1 秒
6. （附帶）按 P 切第三人稱看看自己 → `tp` 變了一次（P 鍵不能改，可直接寫）

### 2 `recv` 接球
教練站在對面場，把球拋過網、落在玩家附近（每次失敗或成功後 2 秒再拋下一顆）。
1. 看地上的落點圈，走進圈裡（不用按鍵）→ 球落地前玩家在預測落點 0.8 m 內
2. 球快到時按接球鍵 → `recv` 事件
3. 按住蹲下鍵再接 → `recv` 且 `crouch`（教練這步拋低一點、快一點）
4. 球落在 3～4 m 外：按住衝刺鍵再按接球鍵撲過去 → `dive` 後接到（`recv` 且 `dive`）；連續 3 次都沒接到就放寬成「有撲出去」也算，提示寫清楚

### 3 `set` 舉球
教練在玩家前方把球拋高給玩家（或陪練把球墊給玩家）。
1. 球過來時按 1 → `set` 且 `n=1`（說明：1 前舉到 4 號位）
2. 按 2 快攻、按 3 後舉 → 兩個都做到（依序或任意順序都可以，面板顯示已完成的）
3. 4、5（或 6）鍵：照 gym.html 現有的意思寫提示（先查 `vbSet` 各數字是什麼），做到任一個
4. 拖滑鼠選舉法：按住 1（或 2、3）不放，滑鼠往左或右拖再放開 → `set` 且 `menu` 為真且不是預設舉法

### 4 `atk` 攻擊（工作單 B）
陪練舉球（現有 `vbNpcToggle('set')`）：玩家把球拋給陪練（F）或教練直接把舉球送到攻擊點。
1. 助跑起跳：往網跑、按空白鍵 → `jump` 且 `!block` 且 `speed` ≥ 2
2. 空中按住左鍵蓄力、放開打到球 → `atk` 且 `air` 且 `chg` 不是 null
3. 甜蜜點：蓄力條到金色就放 → `atk` 且 `zone === 'sweet'`（面板說明金色＝最大力又最準、紅色＝過頭）
4. 吊球：空中按右鍵 → `atk` 且 `tip`

### 5 `serve` 發球（工作單 B）
教練把球交給玩家（現有 `grabBall`），玩家站在底線後；每發完一顆自動再給一顆。
1. 拿著球按左鍵站發 → `serve` 且 `type==='std'`（提示：對面紅圈是落點，轉頭調左右、滾輪調深淺）
2. 按右鍵站飄 → `type==='float'`
3. 按空白鍵拋球起跳，空中按左鍵跳發 → `type==='jump'`
（跳飄可以當附帶說明，不必強制）

### 6 `block` 攔網（工作單 B）
教練站對面網前把球扣向玩家這邊（球路固定、速度中等，讓人攔得到）。
1. 站到網前地上的圈，球被扣的時候按攔網鍵起跳 → `jump` 且 `block` 且離網 ≤ 1 m
2. 空中左右移滑鼠移手（封直線或斜線）→ 空中 |blkAim| ≥ 0.2
3. 攔到球 → `block` 事件（任何碰到都算；`stuff` 顯示「攔網成功！」）
4. 雙人攔網：教學在玩家旁邊放一個隊友（用現有 AI 角色外觀），玩家起跳攔網時隊友也一起跳；站在隊友旁 1.5 m 內一起攔到球 → `block` 且 `mate`
