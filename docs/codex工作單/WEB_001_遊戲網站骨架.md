# 工作單 WEB-001：網站改成遊戲網站（骨架＋大廳畫面）

建立：2026-11-04。總規劃在 `D:\開排球場\tickets.md` 的 Ticket 4，請先讀完（特別是「大廳主畫面樣式」和「底部系統功能」兩段）。
大廳樣式參考圖：`D:\開排球場\設計參考\大廳_目標樣式.webp`。

## 背景
- 網站專案：`D:\開排球場\volleycourt`（Vercel 專案 volleycourts，從 GitHub `main` 自動部署）。
- 使用者決定：網址整個改成排球遊戲網站；球館企劃不再放網路，只留在使用者電腦（本機的 `planning-site` 分支，**不要動、不要刪、不要推送**）。
- 玩法、手感、球、擊球、AI、連線程式全部沿用 `gym.html` 現在的樣子，**這張單不准改玩法**。
- 只做電腦版，不做手機版版面、觸控、搖桿。

## 分支
從 `main` 開新分支 `game-site`（不是從 planning-site）。**不要推送**、不要動 `main`。

## 要做的事

### 1. 拿掉企劃內容
- 刪掉只給企劃用的頁面和資源：`demo.html`、`checklist.html`、`eval.html`、`vbtv.html`、`plan/`、`allnav.js`（全部功能選單）、`spike3d.js`（開場動畫）、`api/geocode.js`、`api/hall.js`、`video/`、`files/`。每一個刪之前先 grep 確認 `gym.html` 遊戲部分沒有用到；有用到的留著，寫進報告。
- **保留** `data/sites.json`（遊戲載入 `site=bs-shenjing` 要讀它，另外有排程會更新這個檔，格式不能動）、`models/`、`sfx/`、`img/` 裡遊戲用到的東西、`api/rt-token.js`、`api/rt-config.js`、`rt-worker/`。
- `README.md`、`部署說明.md` 改寫成遊戲網站的說明（短就好）。

### 2. `gym.html` 改成「遊戲頁」
- 從大廳進來的網址格式：
  - 開房／加入：`gym.html?site=bs-shenjing&room=代碼&mode=模式`
  - 練習：`gym.html?site=bs-shenjing&practice=1`
- 一律固定載入 bs-shenjing 這座球館，直接進入可以走動、打球的畫面：不顯示企劃用的頂列（sitebar）、平面圖編輯、擺放設備、估價等企劃介面。用隱藏或條件判斷做，**不要大段刪除 gym.html 的程式**，免得動到玩法。
- 有 `room` 參數就自動用大廳存的暱稱（localStorage `vb.mp.name`）加入該房間（沿用現有 `netJoin`）。沒有任何參數直接開 `gym.html` → 導回 `index.html`。
- 遊戲裡原本「離開房間」或「回首頁」的地方改成回大廳 `index.html`。
- `NET_MAX` 從 12 改成 20（一間房最多 20 人）。

### 2B. 拿掉 Valorant（瓦羅蘭）角色，大家都用原本內建的人
使用者 2026-11-04 要求。網站要公開，不能放別人遊戲的角色。
- 刪掉 `CHARS` 裡所有 Valorant 特務（Jett、Sage、Reyna、Phoenix、Raze、Killjoy、Omen、Skye、Neon、Viper、Sova、Brimstone、Cypher、Yoru 等）、專屬髮型設定（例如 `jett` 的瀏海參數）、`charThumb` 縮圖，以及檔案裡所有提到 Valorant、特務名字的註解和文字。
- 所有人一律用原本內建的人形（現在 `myChar()` 回傳 `null`／選「原本的人形」時那個），用球衣顏色分隊、分人：
  - 自己、連線的其他玩家、AI 隊友、AI 對手全部都是。
  - AI 的名字改成不帶角色名，例如「AI 隊友」「AI・主攻」「AI・舉球」（6 對 6 沿用 `V6_TAG` 的位置名稱）。
- 拿掉選角色的介面（`rk-menu` 裡的角色格子）和 localStorage `vb.char`；連線訊息裡的 `ch` 欄位收到什麼都當成內建人形，舊版的人連進來也不會壞。
- 通用的造型函式（例如 `makeChibi`）：如果拿掉特務資料後還能用一般參數（膚色、髮型、上衣顏色…）做出人物，就先留著、不要呼叫，留給之後的捏臉工作單 WEB-005 評估；做不到就一起刪。報告裡寫你選哪個。
- 只動外觀，不改身高、碰撞、擊球高度等任何判定。

### 3. 新的 `index.html`：遊戲大廳畫面
照參考圖和 Ticket 4 的「大廳主畫面樣式」做，深色實心面板、橘色主色、青綠色輔色，字型用 Google Fonts 的 Noto Sans TC。這張單先做**畫面和本機能做到的功能**，大廳伺服器（真的房間清單、在線玩家、聊天）是下一張 WEB-002。

- **暫時的暱稱登入**：第一次進來跳出視窗輸入暱稱（之後會換成 Google 登入），存在 `vb.mp.name`。
- **頂列**：左邊遊戲名稱（先用「排球遊戲」，不要用參考圖上的名字）＋連線狀態；右邊「開啟房間」「練習模式」「快速加入」、模式篩選、重新整理。
- **開啟房間**：跳出設定視窗：房名、模式（列出網頁版現有的比賽模式，至少 2v2、6v6）、密碼（選填，WEB-002 才會真的檢查）。按確定就產生房間代碼，進 `gym.html?site=bs-shenjing&room=代碼&mode=模式`。
- **練習模式**：進 `gym.html?site=bs-shenjing&practice=1`。
- **房間列表**：先顯示空狀態，另外放一個「用代碼加入」輸入框（WEB-002 有清單後拿掉）。房間卡片的元件先寫好（房號、模式標籤、鎖頭、等待中／比賽中、房名、人數、延遲），用假資料在開發模式（網址加 `?demo=1`）才顯示，方便看樣式。
- **在線玩家**：先只顯示自己（置頂、標示「你」）。
- **大廳留言板**：先放系統公告（歡迎訊息）和輸入列，送出先只顯示在自己畫面。
- **底部功能列**：角色資訊、成就系統、天梯排行榜、球衣與裝備、系統設定。這張單只做按鈕，按下去顯示「即將開放」。
- 畫面右上不要放參考圖的「問問 Gemini」。參考圖上的玩家名稱、房名不要照抄。
