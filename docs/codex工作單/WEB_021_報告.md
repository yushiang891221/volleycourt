## 新動作資料格式

在 `EMO_KEYS` 增加以動作代碼為鍵的陣列，並在 `EMOTES` 加入對應名稱與圖示，即可走相同本機與遠端入口。

```js
example: [
  { dt: 0, pose: 'idle', move: [0, 0] },
  { dt: 0.2, pose: { sh: [[-0.2, 0.3], [-0.2, 0.3]], el: [0.2, 0.2], tw: 0.1 }, ease: 'smooth', move: [0.2, 0] },
  { dt: 0.3, pose: 'idle', ease: 'smooth', move: [0.2, 0] },
]
```

- `dt` 為從前一格到這格的秒數，第一格使用零，其餘使用正數。
- `pose` 可以是既有 AVP 名稱，或部分關節物件。缺少的欄位以 AVP.idle 補齊。可用 sh、el、hip、kn、hab、shy、sp、tw，陣列順序為右側、左側。
- `ease` 屬於抵達這格的區段。`linear` 為線性，`out` 為二次減速，`smooth` 或省略為 smoothstep。
- `move` 為相對動作起點的累積公尺數，第一項是角色右方，第二項是角色前方。每格都提供兩項，最後一格的值就是終點。
- 左方向交換左右關節、反轉 tw 與橫向位移。播放器關閉一般走路的 arm／gait 擺動。
- `emoKeySample` 回傳 pose、move、done。`emoKeyDuration` 加總時間。`emoKeyPosition` 將曲線轉成世界座標並做子步碰撞。
- 最後一格使用 idle，move 保留終點即可完成收腿且停在新位置。新資料應以自然站姿開始，水平移動期間遵守現有碰撞限制。
