# 工作單 WEB-021：新表情動作「閃身步」

建立：2026-11-13。在 `volleycourt` 的 `game-site` 分支做（目前 main＝game-site＝b539cc7）。只做電腦版。
Codex 用量不可超過 50%；做完就停，額度快不夠時先把進度寫進報告。

## 使用者要的
最近爆紅的花鼓燈基本功「閃身步」，做成玩家可以從 T 輪盤使用的表情動作。之後還會做「浪子踢球」「狗熊哆嗦毛」，所以**動作播放要做成可以重複使用的關鍵影格系統**。

參考截圖在 `D:\開排球場\codex工作單\WEB_021_參考圖\`（閃身步_1～9.png；1～5 是火柴人教學圖、6～9 是真人示範）。

## 動作拆解（使用者描述＋截圖）
以「往右閃」為例，往左就左右鏡像：
1. **準備**（約 0.15 秒）：自然站直、核心收緊，雙手微微離開身體。（圖 1「反方向蓄力」、圖 9）
2. **反方向蓄力**（約 0.25 秒）：雙手一起往**反方向**（左邊）擺過去，上半身跟著往左稍微扭、重心稍往左。（圖 1、圖 6）
3. **瞬間閃出去**（約 0.12 秒，要很快、有「瞬間位移」的頓挫感）：
   - 雙手**瞬間**甩向要去的方向（右邊），手臂接近水平指向右邊。（圖 2、圖 7、圖 8）
   - **後腳（左腳）往後蹬**，**前腳（右腳）往右大步邁出去**；身體整個往右平移約 0.7 m，上半身保持直立、核心收緊（圖 4「核心極限收緊」、圖 5 的殘影就是平移的過程）。
   - 中途兩腿會交叉成 X（圖 3「前腳無負擔」：前腳不吃重量、輕輕帶過）。
4. **定住**（約 0.15 秒）：大弓步、後腳斜斜伸直、手還指著右邊。（圖 4、圖 8）
5. **收腿**（約 0.3 秒）：後腳收回來，回到自然站姿（停在新位置）。（圖 9）

整段約 1 秒。節奏重點是「慢慢蓄力 → 一瞬間閃過去 → 定住 → 收」，第 3 段一定要比其他段快很多。

## 要做的事
1. **關鍵影格動作系統**：在 gym.html 的表情動作裡，新增一個通用的「一串關鍵姿勢＋每段時間＋緩動方式」播放器（參考撲救的 `avDiveKey`／`avDrive` 做法，用 `AVP` 那套關節：肩 `sh`、肘 `el`、髖 `hip`、膝 `kn`、髖外展 `hab`、肩 `shy`、身體 `sp`、扭轉 `tw` 等）。支援左右鏡像、整個人的水平位移曲線。之後的「浪子踢球」「狗熊哆嗦毛」只要加資料就能用。
2. **閃身步**：
   - 代碼 `shanshen`（伺服器只接受 `^[a-z0-9]{1,12}$`），名稱「閃身步」，圖示自己挑。加進 `progress.js` 的 `EMOTES`，**一開始就能用**（不用等級、成就）。在「球衣與裝備 → 動作與表情」可以放進 T 輪盤；預設輪盤不變。
   - 方向：按下時有按著左右移動鍵就往那邊；沒有就**每次左右交替**（第一次往右）。
   - **真的會移動**：自己的角色照位移曲線真的往旁邊移約 0.7 m（`walk.x`、`walk.z`，以角色面向的左右為準），會被牆、球網、場邊物件擋住就少移一點，不能穿過去。
   - 播放期間不能走路、跳、擊球；可以被打斷的情況照現有表情（例如被球打到、開始比賽）。
   - **發球之後到死球之前不能用**（使用者明確指定；避免當成衝刺用）：從發球員拋球／擊出發球那一刻起，到這一球判分（死球）為止都不能用——包含 `VM.phase === 'rally'`，以及發球員已經在拋球（`walk.serve`／`walk.jserve` 進行中）的時候。死球後、等待發球（還沒拋球）、場下、觀眾、練習都可以用。不能用時按了就提示「發球後到死球前不能用」。
   - 如果正在播放時剛好發球了（例如別人先發），立刻中斷動作、回到站姿，位移停在當下位置。
3. **連線**：按下時只送**一則** `emo`（帶動作代碼、方向、起點 x、z、面向），別人的電腦自己照同樣的關鍵影格播放，起點用訊息裡的位置、照現在時間播放（不要被 WEB-018 的延遲播放拖慢，做法參考 WEB-018 真人起跳「靠到起跳點、照現在時間播」）；播完再回到一般位置同步。不能增加定時傳送。
4. 第三人稱和第一人稱都要正常（第一人稱時鏡頭跟著平移，不要劇烈搖晃）。觀眾看場上的人跳也要正常。

## 不要做
- 不改其他表情、擊掌、嘲諷的行為。不改比賽、AI、評分、聊天。不做手機版。不改 `blender/`、`models/`、`rt-worker/`、SQL。不推送、不部署。一行程式中間的註解用 `/* */`。
