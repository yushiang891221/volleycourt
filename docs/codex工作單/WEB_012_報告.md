## 完成內容

- 好友邀請通知會在大廳和房間右下角出現，提供接受、拒絕與檢視檔案。邀請數增加及初次登入有待處理邀請時抓取好友清單。平常僅查計數，未讀私訊增加不觸發整份清單讀取。
- 通知以 sessionStorage 去重，讀寫皆有 try/catch。比賽進行時隱藏卡片並暫存新邀請，回到房間後顯示。接受或拒絕後更新清單、移除通知並更新紅色數字。
- 大廳、房間和好友面板的名字支援右鍵選單，並加上「按右鍵查看更多」提示。自己的名字不開選單。選單會避開視窗邊界，點外面、按 Esc、捲動或調整視窗大小時關閉。
- 好友關係分別顯示加好友、取消已送出邀請、接受好友邀請與傳私訊。私訊會選到指定好友。訪客保留檢視檔案入口，好友按鈕停用並顯示登入提示。
- 好友關係快取 60 秒，並共用進行中的查詢。關係操作後重新整理，避免顯示舊狀態。
- 個人檔案使用現有角色 preview、等級算法、成就名稱及系列圖示，顯示外觀裝備、球隊球衣、暱稱、等級、稱號、球隊、勝敗與可捲動成就清單。預覽明確使用對方球隊球衣，避免套到查看者的球衣。
- 新增 `010_public_profile.sql`，限制 authenticated 執行，撤銷 public 與 anon 權限。查不到暱稱回傳 null，未登入會拒絕。回傳欄位採白名單，沒有 email、coins 等帳號資訊。
- 訪客與尚未建立 SQL 函式時顯示中文訊息。角色預覽載入失敗也會顯示提示。
- 設定面板隱藏 J／K／L 三列，保留內部預設值、按鍵讀取和既有存檔。遊戲仍使用這些內部按鍵，因此採只隱藏介面的做法。

## 計數介面與連線決定

原有 `friend_badge()` 只有私訊與邀請的合計，無法可靠分辨邀請增加。因此在 010 SQL 新增 `friend_badge(p_details boolean)` 多載，回傳 incoming 與 total 兩個計數，保留原本無參數函式供既有呼叫使用。未執行 010 時，前端會退回好友清單讀取，執行後採精簡計數流程。

檢查 `rt-worker/src/lobby.js` 後，大廳協定沒有指定玩家通知功能，因此使用每 60 秒查詢，切回頁籤時也會檢查，未增加伺服器訊息協定。
