# 工作單 WEB-005D：捏臉畫面背景改成遊戲房間裡的球場

建立：2026-11-09。在 `volleycourt` 的 `game-site` 分支做；開工前先確認工作目錄乾淨（`blender/`、`models/` 是 Claude 正在做的，不要動也不要提交）。
只做電腦版。**這張允許修改 `creator.js`（只改背景與鏡頭相關的部分，不改格子介面和角色造型）。**

## 背景
使用者明確要求：捏臉畫面的背景要是**遊戲房間裡的那座球場**（`gym.html?site=bs-shenjing`），不是 `creator.js` 現在自己畫的簡單球場。WEB-005C 報告第 7 點說 `openCreator` 沒有背景參數所以沒做，這張補上。
捏臉畫面是在大廳（index.html）開的，那時候球館場景沒有載入；直接在大廳載入整座球館太重，所以用**事先拍好的背景圖**。

## 要做的事
### 1. 從遊戲球館拍背景圖
- 在 `gym.html` 加一個只給開發用的網址參數（例如 `?site=bs-shenjing&shot=creator`）：載入球館後，把鏡頭擺在**球場邊線附近、看向場中**（看得到地板、場線、網子和看台），高度約 1.1 公尺、視角 32 度（跟 `creator.js` 的相機一致），藏起所有介面、不放任何球員，畫面品質開到最高，算出一張圖。
- 存成 `assets/creator-bg.jpg`（2560×1440，品質 0.88 左右）。可以用 headless 瀏覽器自動截，或寫一個 `tools/shoot-creator-bg.cjs`；做法寫進報告，之後球館改了可以重拍。
- 角色要站的位置在畫面中間偏左（右邊是格子面板），那一塊地板要乾淨（不要剛好有網柱或線擋住）。

### 2. `creator.js` 改用背景圖
- `openCreator` 加選項 `background`，預設 `'assets/creator-bg.jpg'`。
- 3D 畫布改透明（`alpha: true`、`scene.background = null`），背景圖用 CSS 鋪滿舞台（`cover`）。
- 原本自己畫的球場（`buildCourt`）只在背景圖載入失敗時才用。
- 地板改成只接陰影的平面（`ShadowMaterial`），角色腳下有柔和的影子。
- 調整角色在畫面的位置和鏡頭（`SHOTS`），讓角色看起來站在照片裡的地板上（腳底不浮空、透視一致）。各部位拉近的鏡頭也要跟著對。
- 燈光色調配合球館照片（暖色或冷色依照片），不要讓角色看起來是貼上去的。

## 不要做
- 不改格子介面、角色造型（`avatar-toy.js`）、外觀代碼。
- 不改物理、擊球、AI、連線。
- 不推送、不部署，不動 `main`、`planning-site`、`blender/`、`models/`。

## 驗收
1. `character-creator.html` 和實際遊戲流程（清掉外觀 → 開始遊戲）都看得到遊戲球場當背景，角色站在地板上、有影子。截圖放 `codex工作單/WEB_005D_截圖/`（全身、拉近頭、拉近腳各一張）。
2. 背景圖載入失敗時退回簡單球場，不會白屏。
3. 舊的自動檢查（含 `verify-web005c.cjs`）都還要過。
