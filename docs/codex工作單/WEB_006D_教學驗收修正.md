# 工作單 WEB-006D：新手教學驗收後的修正

建立：2026-11-10。在 `volleycourt` 的 `game-site` 分支做（WEB-006C 已提交 b2a9dad）。只做電腦版。
Claude 在 `http://localhost:5190/gym.html?practice=1&tutorial=1&debug=1` 實際把六段走完了，流程、進度存檔、改鍵提示都正常。下面是要修的問題，**照順序全部修完**；不要因為擔心用量提早停，只有 Codex 顯示帳號額度不足才停。

## 要修的問題
1. **攔網：教練扣球沒有預兆，真人抓不到時機（最重要）。** 現在 `TUT_COACH.feed()` 的攔網球是憑空出現在對面 3.3 m 高直接扣過來，約 0.4 秒就到網前。改成像真的攻擊手：教練先把球往上拋（約 1 秒，看得到球升起、落下），教練角色做起跳／揮臂姿勢，球到最高點附近再扣過來（球路仍用現在試算過、攔得到的那條，用 `vbLaunch`）。提示文字改成「看教練把球拋起來，他起跳時你也按 B 起跳」之類（B 要照按鍵設定）。請用程式模擬「看到教練拋球後 X 秒按 B」，找出一個讓真人反應（拋球後 0.4～0.8 秒按）就攔得到的節奏，寫進報告。
2. **攔網：接球微輔助會把玩家從網前圈拉走。** 玩家站進網前黃圈（離網 0.7 m）後，`vbAssist` 會把人往後拉到離網 1.1～1.5 m，結果「離網 1 m 內」不成立、教練也不扣。教學攔網段時不要讓 `vbAssist` 拉人（只在教學攔網段，其他模式不變）。
3. **接球第 1 步不用移動就過關。** 現在球落在玩家站的地方。改成每顆球落在**玩家目前位置**旁 2～2.5 m（隨機前後左右，但要在自己場內），讓玩家真的要走進落點圈。
4. **撲救那步球落點不對。** 現在落點是固定的 `world(5, 3.5)`，玩家撲過一次後位置變了，下一顆球可能落在 0.2 m 或 7 m 外（撲救最多 5 m）。改成每顆球都以**玩家當下位置**為準，落在側邊 3～3.5 m、場內；或每顆球前把玩家放回起點，二選一，寫進報告。
5. **失敗提示文字不分段落。** 攔網、攻擊、舉球失敗時也顯示「等球靠近身體、亮起來再按，先看落點站好」（接球用的）。每段要有自己的失敗提示，例如攔網「早一點按 B，跟教練起跳同時」、攻擊「等球掉到頭頂前上方再起跳」、舉球「球掉到額頭前上方時再按」。另外一步做到時、整段完成時要把舊的失敗提示清掉（現在完成畫面還殘留上一句）。
6. **教學面板擋到左上角「練習模式」房間資訊框，也蓋到上方「陪練舉球／陪練對碰」那排按鈕。** 面板改放在畫面上方中間、那排按鈕的下面，不要跟房間資訊框、右上準備框、右側操作說明重疊（視窗 1280×720 和 1920×1080 都要檢查）。
7. **教學選單在「進入球館中…」載入畫面還沒結束就跳出來**（`tutorial=1` 重新整理時看到選單疊在載入畫面後面）。等載入畫面消失、真正進入球館後再開。

## 不要做
- 不改玩法、物理、數值、擊球判定、AI、連線、比賽規則（攔網球路、教練拋球都是教學專用）。不做手機版。不改 `blender/`、`models/`。不推送、不部署。一行程式中間的註解用 `/* */`。
