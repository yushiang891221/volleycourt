# 工作單 WEB-006B：新手教學後三段（攻擊、發球、攔網）

建立：2026-11-10。在 `volleycourt` 的 `game-site` 分支做。只做電腦版。
**先讀 `codex工作單/WEB_006_新手教學設計.md` 和 `codex工作單/WEB_006A_報告.md`**，沿用 A 做好的 `tutorial.js` 框架、`tutEv` 事件、`TUT_COACH`。

## 範圍
1. 段落 4 `atk`、5 `serve`、6 `block` 全部步驟可以做完；選單上這三段改成可以點。
2. `TUT_COACH` 補上這張需要的教練動作：
   - 攻擊：用現有陪練舉球（`vbNpcToggle('set')`），或教練直接舉到攻擊點，兩種選一個穩定的；教學結束要把陪練收掉。
   - 發球：把玩家帶到自己場的底線後、給球（`grabBall`）；每發完一顆約 1.5 秒後自動再給。
   - 攔網：教練站對面網前，把球扣過網到玩家前方網前（固定球路、中等速度、攔得到）；玩家站在網前圈裡才扣。
   - 雙人攔網：在玩家旁邊放一個隊友（現有 AI 角色外觀，例如 `vmMkAi` 或 `makeAvatar`），玩家按攔網鍵時隊友也跳起來；`block` 事件的 `mate` 要正確。隊友只在教學這一步出現，結束要收掉，不能留在場上。
3. 六段都完成時的恭喜畫面。
4. `tools/verify-web006.cjs` 擴充到 4～6 段。

## 先查清楚再動手（寫進報告）
- `serveLaunch`、`jumpServeHit` 的 type 實際值，對應到事件的 `std/float/jump/jfloat`。
- `vbBlockTest` 碰到攔網手的判定，事件放的位置；隊友 AI 攔網的現有寫法（比賽裡 AI 怎麼攔），能用就用，不要另寫一套物理。
- 教練扣球要用現有的發射函式，速度和高度要能被正常攔到（自己用 debug 的 `window.__gym` 或 node 算一下軌跡，寫進報告）。
