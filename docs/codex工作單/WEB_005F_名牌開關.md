# 工作單 WEB-005F：設定加「顯示球員名牌」開關

建立：2026-11-10。在 `volleycourt` 的 `game-site` 分支做。只做電腦版。小工作單。
**不改玩法、物理、擊球、AI、連線協定。**

## 使用者要求
遊玩中球員頭上的名牌（`.mp-tag`，`CSS2DObject`）要能在設定裡關掉。

## 現況
- 名牌在 `gym.html` 多處建立：遠端玩家（約 7466、10054 行）、AI（約 8390、9956 行）、陪練（約 9687 行）、還有 10350 行那個黃色的（先查清楚是什麼，如果是提示性質的、不是球員名牌，就不受開關影響，寫進報告）。
- 設定在 `settings.js`：`defaults()`（約 15 行）、布林欄位清單（約 21 行）、「畫面」分頁（約 60 行）。`showFps` 是現成的例子，照它做。

## 要做的事
1. `settings.js`：新增布林設定 `nameTags`（預設 `true`＝顯示），加進布林欄位清單和舊設定遷移；「畫面」分頁加一個勾選「顯示球員名牌」，放在「顯示 FPS」附近。
2. `gym.html`：所有球員名牌（玩家、AI、陪練）依 `VBSettings.values.nameTags` 顯示或隱藏。**改了馬上生效、不用重新整理**，之後新加入的球員也要遵守。
   - 建議做法：在 `body` 加一個 class（例如 `hide-nametags`），CSS 寫 `.hide-nametags .mp-tag { display: none; }`，設定改變時切換 class；這樣不用逐一追蹤每個名牌。如果 `CSS2DRenderer` 會覆蓋 `display`，改用 `visibility: hidden`，寫進報告。
3. 自己的名牌如果有，一起受開關控制。

## 不要做
- 不改名牌樣式、不改其他設定。
- 不推送、不部署，不動 `main`、`planning-site`、`blender/`、`models/`。

## 驗收
1. 設定 → 畫面 → 取消「顯示球員名牌」：場上所有球員（含 AI）名牌立刻消失；再勾回來立刻出現。
2. 關掉後重新整理，設定會記住（仍然隱藏）。
3. 舊的自動檢查都還要過；新寫 `tools/verify-web005f.cjs`（設定預設值、存取、遷移、切換 class 的函式）。
4. 沙盒連不到 CDN 而無法實際看畫面的話，寫進報告「待 Claude 驗收」。
